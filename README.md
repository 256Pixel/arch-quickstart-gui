# Arch Quickstart GUI

## About
### Functions
1. Installing some apps
2. Install and add some rules for security (firewalld)

## Usage
Run the following command in your terminal to download and launch the GUI:
```bash
curl -LO https://github.com/256Pixel/arch-quickstart-gui/releases/latest/download/arch-quickstart-gui && chmod +x arch-quickstart-gui && ./arch-quickstart-gui
```

## Prerequisites for development
- Golang

## Development commands
Run the program:
```sh
go run .
```
